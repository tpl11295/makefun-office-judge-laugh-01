## Entry

`main.ts` writes a single one-line office joke to `/output/entry.txt`:

> "The office plant has survived three managers, two layoffs, one rebrand. It is the only one of us with job security."

The humour comes from the reversal: everything in the office changes — the people in charge, the headcount, even the brand — except the plant, which quietly outlasts them all and ends up with the most stable job in the building.

## Run

```bash
node main.ts
```
